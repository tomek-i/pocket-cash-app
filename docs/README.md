# Pocket Cash Documentation

Design and reference docs for Pocket Cash, a local-only, offline-first personal
finance desktop app. It is a Turborepo monorepo using Next.js and React, an
embedded PGlite database with Drizzle, Tailwind and Biome. Web and Electron share
one UI, it is single-user, and there is no cloud.

| Doc                                | What it is                                                                                                                       |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| [development.md](development.md)   | Running it locally, repo layout, common scripts, testing, regenerating screenshots, and building the installer.                  |
| [architecture.md](architecture.md) | How web and Electron share one UI and codebase over an embedded PGlite database. The layers, key decisions, and desktop specifics. |
| [releasing.md](releasing.md)       | How versions and the Windows and macOS builds are cut, automated with release-please and Conventional Commits, plus the macOS Gatekeeper step. |

[`assets/`](assets/) holds the product screenshots used by the README and the
landing page. They are generated by a script, not captured by hand. See
[development.md](development.md#screenshots).

The root [`README.md`](../README.md) is the product overview. `CHANGELOG.md` is the
release history.
