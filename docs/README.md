# Pocket Cash — Documentation

Design and reference docs for Pocket Cash — a local-only, offline-first personal
finance **desktop** app (Turborepo monorepo: Next.js + React, embedded PGlite +
Drizzle, Tailwind, Biome; web + Electron share one UI, single-user, no cloud).

| Doc                                | What it is                                                                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| [development.md](development.md)   | Running it locally, repo layout, common scripts, testing, regenerating screenshots, and building the installer.                |
| [architecture.md](architecture.md) | How web + Electron share one UI/codebase over an embedded PGlite database; the layers, key decisions, and desktop specifics.   |
| [releasing.md](releasing.md)       | How versions and the Windows + macOS builds are cut — automated via release-please + Conventional Commits — and the macOS Gatekeeper step. |

[`assets/`](assets/) holds the product screenshots used by the README and the
landing page; they are generated by a script (see
[development.md](development.md#screenshots)), not captured by hand.

The root [`README.md`](../README.md) is the product overview; `CHANGELOG.md` is the
release history.
